Feature 1: text-wrap: balance;

text-wrap: balance; will make rows with text balanced. It is especially useful with centered headers. Supported from Chrome 114.

This paragraph has normal text wrapping. You can see how rows have different amounts of text in them, especially when text-align: center;

This paragraph has balanced text wrapping. You can see how rows have the same amount of text in them, even the last row.

Feature 2: :has-selector

:has -selector checks if the element contains selected property, and changes styling for that container only.
