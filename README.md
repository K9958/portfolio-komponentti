# Web Shop Frontend "Komponentti"

## Komponentti - PC-komponenttien verkkokauppa

## Yleiskuvaus
Komponentti on React-pohjainen verkkokauppasovellus, joka on erikoistunut tietokonekomponenttien myyntiin. Sovellus tarjoaa seuraavat ominaisuudet:

## Pääominaisuudet
- Tuotteiden selaus kategorioittain (näytönohjaimet, prosessorit, emolevyt jne.)
- Ostoskoritoiminnallisuus Redux-tilanhallinnalla  
- Responsiivinen käyttöliittymä Bootstrap-komponenteilla
- Tuotteiden yksityiskohtaiset tuotesivut
- Suomenkielinen käyttöliittymä

## Tekninen toteutus
- React + React Router reititystä varten
- Redux Toolkit tilanhallintaan
- React Bootstrap käyttöliittymäkomponentteihin  
- Ostoskorin tietojen tallennus selaimen local storageen

Sovellus on rakennettu Create React App:in päälle ja hyödyntää moderneja React-käytäntöjä kuten funktionaalisia komponentteja ja React Hooks:ia.
